# Second Wife Restaurant — Gonda

Premium responsive restaurant website for Second Wife Restaurant, Janki Nagar, Gonda, Uttar Pradesh.

## Features
- Immersive restaurant-style landing page
- Responsive mobile/desktop layout
- Filterable menu highlights
- Call, WhatsApp, directions and order-on-WhatsApp CTAs
- Reservation form captured by Netlify Forms
- Reservation submission opens WhatsApp with reservation details for direct confirmation
- SEO metadata and security headers

## Reservation workflow
1. Guest submits the reservation form.
2. Netlify Forms receives the submission.
3. The site shows a confirmation state.
4. WhatsApp opens with the reservation details so the restaurant can confirm availability directly.

For email notifications, enable Netlify Forms email notifications in the Netlify project settings.
